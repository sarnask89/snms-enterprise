## 2025-02-14 - Modernizing Finances Module for Polish Language and Better Key Accessibility
**Learning:** Icon-only action buttons within table rows (like edit/delete actions) or card dashboards often lack accessible labels or have inconsistent design language when migrated from legacy systems. In Poland-focused target groups, localized descriptive `aria-label` elements in screen readers provide precise guidance, while standardizing color tokens (`success`, `neutral`, `error`, `warning`) ensures consistent aesthetic contrast across the system. Standardizing on Lucide icons ensures consistent scale and stroke weight, while substituting raw browser `confirm` triggers with proper UI Toast notifications bridges visual flow during save/delete actions.
**Action:** Next time, ensure all edit, delete, and addition icons have appropriate, Polish localized `aria-label` tags, standardize on Lucide prefixed `i-lucide-` icons instead of legacy Heroicons, swap native checkboxes with accessible `UCheckbox` controls, and integrate `useToast` to inform the user about synchronous/asynchronous action results.
