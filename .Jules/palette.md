## 2026-06-16 - [UX Modernization Standards]
**Learning:** Modernized pages in the Nuxt frontend (like `customer-devices.vue`) use Nuxt UI v3 patterns (`v-model:open`, `#content` slot). Secondary/outline buttons should use `color="gray"` instead of `neutral` for consistency. Lucide icons are preferred over legacy Heroicons.
**Action:** Always check `customer-devices.vue` for the current UI component standards and use `color="gray"` for secondary actions.
