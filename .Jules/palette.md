## 2025-02-23 - Standardization of ARIA Labels and Live Notifications for Analytics/Reporting Actions
**Learning:** In highly technical applications (such as CRM networks with GIS/PIT exports), the user interface can often feel silent or "stuck" when operations run asynchronously in the background (e.g., generating XML, GML, or CSV exports). Providing both explicit Polish ARIA labels (e.g., `aria-label="Pobierz raport PIT w formacie GML"`) and reactive loading states coupled with instant toast notifications (`useToast`) ensures that screen reader users and visual operators alike get clear, real-time feedback on the lifecycle of critical processes.
**Action:** Always map standard Polish ARIA action labels on controls while implementing a loading feedback loop with instant success or error toasts for any remote analytical or export-related calls.
