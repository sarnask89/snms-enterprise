## 2025-02-14 - Standardizing Customer Profile dossier UX and accessibility
**Learning:** Migrating legacy styling constructs (explicit color names like red, green, amber, gray, and custom icons) to standard Nuxt UI v4 semantic tokens (neutral, success, warning, error, primary) ensures high accessibility and styling coherence. Adding localized Polish ARIA labels on all back, edit, and save buttons prevents screen readers from silencing critical state actions. Additionally, fixing the Nuxt UI v4 `UTextarea` property mapping by replacing legacy `:data` with the standard `:rows` attribute ensures robust vertical height rendering across all dashboard panels.
**Action:** Always audit form inputs for standard Nuxt UI v4 attributes (use `:rows` on `UTextarea`) and map badges to semantic color tokens. Equip every actionable icon-only or text button with clear, contextual ARIA labels to maintain strong compliance with UX design guidelines.
