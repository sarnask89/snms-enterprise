## 2026-05-18 - Helpdesk UI Modernization, Accessibility & Toast Feedback
**Learning:** Legacy UI icon sets should be systematically upgraded to modern Lucide equivalents (`i-lucide-*`) to ensure design consistency. High-frequency table list items (such as queues, categories, and tickets) must expose screen-reader-accessible localized ARIA labels on dynamic table actions rather than silent icons. Triggering live, dynamic, semantic toast notifications (`useToast`) on all CRUD and state mutations drastically elevates developer/operator confidence during task management.
**Action:** Apply context-aware Polish ARIA labels (e.g. `aria-label="Edytuj kolejkę ${row.name}"`) and useToast triggers for any interactive forms or dashboard table operations built on Nuxt UI components.
