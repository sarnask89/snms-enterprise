## 2026-06-24 - [Accessible Icon-only Buttons]
**Learning:** Icon-only buttons in the Nuxt UI v4 table actions require explicit `aria-label` attributes for screen readers. The standard pattern is to use `size="xs"`, `variant="ghost"`, and semantic colors (`primary`, `error`).
**Action:** Always include `aria-label` in Polish for icon-only buttons (e.g., 'Pobierz dokument', 'Usuń dokument').
