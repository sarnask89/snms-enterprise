## 2025-05-15 - Dashboard Modernization and Localization
**Learning:** Transitioning from technical strings (e.g., 'active') to localized labels (e.g., 'Aktywny') significantly improves accessibility and user experience in a localized application. Additionally, shifting to semantic color tokens (`success`, `neutral`) ensures better theme consistency than hardcoded colors (`emerald`, `gray`).
**Action:** Always prefer localized labels for status fields and use semantic color tokens in Nuxt UI components.
