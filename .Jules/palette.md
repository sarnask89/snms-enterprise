## 2025-09-11 - Floating Widget ARIA and Icon Consistency
**Learning:** Floating widget trigger buttons with CSS animations require `:aria-expanded` attributes and explicit ARIA labels for screen reader clarity, alongside replacing legacy Heroicons with system Lucide icons (`i-lucide-*`).
**Action:** Always verify floating/docked interactive components have `aria-label`, `:aria-expanded`, and modern Lucide icon names.
