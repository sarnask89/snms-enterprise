## 2026-06-14 - Standardizing Refresh and Accessibility in Helpdesk
**Learning:** Standardizing the page-wide refresh pattern with a `pendingAny` computed property and a global button in the header provides immediate clarity on data status. Using Polish ARIA labels for icon-only buttons ('Edytuj kolejkę', 'Usuń zgłoszenie') is essential for local accessibility compliance.
**Action:** Always check for missing global refresh controls in dashboard-style pages and ensure every icon-only button has a descriptive ARIA label in the app's primary language.
