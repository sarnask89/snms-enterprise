## 2026-07-24 - [Semantic Theme Tokens and Accessible Inputs in Nuxt UI v4]
**Learning:** Standardizing color/variant properties on interactive elements to Nuxt UI v4 semantic tokens (`neutral`, `success`, `warning`, `error`) instead of hardcoded explicit colors (e.g. `gray`, `emerald`, `yellow`, `red`) ensures proper, contrast-compliant dark mode styling automatically. Replacing native HTML checkbox inputs with standard `<UCheckbox>` components dramatically improves keyboard-accessible focus-visible indicators without requiring custom CSS overrides.
**Action:** When modernizing pages in this design system, always map colors to semantic tokens, add Polish ARIA labels (`aria-label`) to icon-only buttons, and prefer custom framework wrappers (`UCheckbox`, `UTextarea`) over native inputs.
