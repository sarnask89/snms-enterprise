## 2025-05-14 - Polish ARIA labels for icon-only buttons
**Learning:** The application consistently uses Polish for its UI, and interactive elements like table action buttons (pencil, trash, power) require Polish ARIA labels to be accessible and context-aware for screen reader users.
**Action:** Always use Polish translations (e.g., 'Edytuj subskrypcję', 'Usuń subskrypcję') for `aria-label` attributes in this codebase.
