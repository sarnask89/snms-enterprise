## 2026-07-30 - Dynamic Regex Compilation in Line-by-Line Loops
**Learning:** In device output processing (e.g. parsing PON port rx-power outputs on Dasan OLTs), compiling dynamic regex patterns inside loops (like `re.search(fr"{port_id}/...", line)`) introduces significant compilation overhead. However, replacing it with a generic module-level regex pattern like `([^/\s]+)/...` and using post-match string comparison (`match.group(1) == port_id`) breaks when `port_id` can contain slashes (e.g. `"1/1"` in GPON port IDs), leading to incorrect or failed matches.
**Action:** Compile the dynamic regular expression exactly once *outside* the processing loop, using `re.compile(fr"{re.escape(port_id)}/(\d+)\s+(-?\d+\.\d+\s*dBm)")`. This completely avoids loop recompilation overhead while maintaining absolute matching correctness.
