## 2026-09-21 - Batch TERYT Address Resolution During Entity Serialization
**Learning:** In `crm-portal-ts`, entity serialization functions (`serializeCustomer`, `serializeDevice`) were calling `resolveTerytAddress` individually for each item returned in list endpoints (`GET /customers`, `GET /customer-devices`). Because `resolveTerytAddress` sequentially traverses up to 5 location entities (street -> city -> commune -> district -> state), serializing a page of 20 items executed up to 100 individual SQL queries ($5N$).
**Action:** Use `batchResolveTerytAddresses` in list endpoints to collect all address IDs across the list and fetch street, city, commune, district, and state entities in up to 5 batched SQL queries using TypeORM's `In(...)` operator before passing the pre-resolved address objects to `serializeCustomer` / `serializeDevice`.
